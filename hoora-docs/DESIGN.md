# Hoora Docs design contract

An editorial knowledge workspace for Hoora teams: application → release version → vertical → attributed contribution. SOPs and guides remain simple documents in folders.

Geist is self-hosted throughout. Headings use restrained tracking and 600 weight. Body copy uses 14–16 px with comfortable line lengths. Controls use sentence case.

Light palette: ink #191919, secondary #707070, border #eaeaea, canvas #fafafa, surface #ffffff, Hoora yellow #ffda00. Dark palette: ink #ededed, secondary #a0a0a0, border #292929, canvas #161616, surface #111111, same yellow accent. Yellow identifies primary actions, not decorative headings.

The login pairs a charcoal brand panel with a focused form. The workspace uses a persistent navigation rail and document lists. Releases use a clear version list and vertical sections, with contributor identity directly below each contribution. Mobile stacks controls and collapses navigation.

Reference: Vercel analysis retrieved using getdesign.md, retained in VERCEL_DESIGN_REFERENCE.md. The Hoora theme uses its own brand, copy and workflow.
