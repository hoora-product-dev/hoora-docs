# Hoora Docs delivery checklist

This file tracks the agreed product workflows. Completion requires implementation and verification, not only visible buttons.

- [x] Manager-owned teams, invited work emails, team viewer/publisher membership, team document access.
- [x] Backend permission checks for drafts, publication, artifacts, attachments, sharing and notices.
- [x] Stable readable document and application/version URLs; preserve old shared links.
- [x] Search with immediate ranked results, keyboard control, permission-aware full-text/fuzzy service.
- [x] Lightweight submission for links, PDFs, Markdown and standalone HTML; usable previews.
- [x] Release navigation by application, reusable section, independent version and chronological global feed.
- [x] In-app notices with sender attribution, read state and atomic three-hour document cooldown.
- [x] Installable app and opt-in browser push; private documents never cached offline.
- [x] Admin email preview/test recipient remains fixed to Rahul; no company-wide email activation.
- [x] Related knowledge, recently viewed, contribution view, archive/restore and audit trail without edit snapshots.
- [x] Responsive light/dark UI with supplied Hoora logos; accessible forms, loading and error states.
- [x] Live tests for all roles, sharing transitions, direct links, storage and publication snapshots.
- [x] Knip review, removal of unused prototypes/assets/source and clean build output.
- [ ] Production deployment and verification, with accurate remaining limitations documented.
